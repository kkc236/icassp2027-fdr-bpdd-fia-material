## 解释边界

- 当前 run 的 best 高于所有已登记 mAP，但同服务器这些旧 run 的源码、初始状态或 authority 不完全相同；这里是横向算术比较，不升级为严格因果增益。
- 当前 epoch 100 mAP=`0.29511`，比 best epoch 87 低 `0.337 pp`，论文或部署应使用 `best.pt`，不能用 `last.pt` 代表最佳效果。
- 当前模型摘要为 34,119,764 参数、130.2 GFLOPs；旧 FDR+BPDD 记录为约 33,156,614 参数、108.229 GFLOPs。capacity-v2 确实增加了容量与计算量，不能与“零推理开销 BPDD”旧结论混写。
