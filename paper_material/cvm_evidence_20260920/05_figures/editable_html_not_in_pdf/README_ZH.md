# GCDL 结构图 HTML 复刻

依据 architecture_palette_20260919/architecture_muted_final.png 重建，采用相同的 1448×1086 坐标画布、四面板布局和低饱和配色。框、文字、公式和连线均为原生 SVG 元素；没有把整张图片贴进网页。字体由浏览器用 Times New Roman 渲染，字形细节可能与生成位图略有差别。

## 使用

- 双击 `architecture.html` 即可离线打开。全部脚本和样式已包含在这个文件中，没有额外依赖。
- 点击「1:1」按原始像素尺寸查看；「适应宽度」按窗口等比显示。
- 勾选「编辑」后拖动模块，所连线段跟随。选中模块也可用方向键移动，Shift 配合方向键作 1 像素微调。
- 点击线段后，拖动圆点调整端点或拐点；拖动小方块添加拐点。「拉直线段」「恢复选中」「撤销」均可用。
- 修改自动保存到当前浏览器/页面地址。要分享修改后的版本，请点击「保存 HTML」下载带当前布局的独立文件。
- 「导出 SVG」保存可编辑矢量图；「导出 PNG」输出 2896×2172 图片。
- 「只看图」隐藏工具栏，Esc 或右下角按钮返回。

默认完整图的独立导出：`architecture.svg`、`architecture-2x.png`。
