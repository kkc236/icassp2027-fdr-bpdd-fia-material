# UAVDT 服务器结果包检阅

检阅日期：2026-09-19。仅读取和解压材料，未运行包内程序、加载权重、训练或重新评估。

## 结论

本包提供了一组比先前跨运行拼接更容易对应的 UAVDT baseline/exp 结果：总体 AP 从 **14.12 到 16.96（+2.84 点）**，AP50 从 **24.21 到 29.16（+4.95 点）**，三个类别的 AP 均提升。

但是，**归档源码是旧 FDR＋FIA＋训练期 BPDD，和当前论文的 GCDL＋共享 P3＋推理局部专家不是同一实现**。结果对应的实际权重未包含在包中，因此目前应写作“包内联合运行 exp”，不能直接标成当前论文 Full。这个问题是模型身份核对，并不是结果作废。

## 2. 和旧材料的关系

- `exp/` 的 13 个结果文件与 2026-09-15 归档的 `user_export_20260915/` **逐字节完全一致**。这是已有联合结果的更完整交接材料，不能当成一次独立重复实验。
- 本次 baseline 的 AP 为 14.12；旧 `UAVDT_RESULTS_ZH.md` 使用另一运行的 AP 15.60。两者应保留各自身份，不能静默替换。
- 旧报告中的总体 +1.36 AP、truck −2.15 AP，来自另一基线与本联合结果的跨运行差值；不能用于描述本包的两组结果。
- 先前文档根据作者确认将 AP 16.96 标成当前 Capacity-BPDD Full。本次归档源码产生了相反的版本线索；在核对实际模型之前，该归属重新标记为待确认。

## 4. 模型实现核对

包内路径均相对 `extracted/服务器fdr-bdpp-fia-material/`。

| 机制 | 包内实现 | 当前论文 Full |
|---|---|---|
| 解码参考 | preliminary_box=true | incoming reference，preliminary_box=false |
| 几何可行域 | 原始 distance2bbox | 保中心、尺度及精度相关的 extent floor |
| FGL 权重 | 原始 detached matched IoU | LQS，初始收缩系数 0.25 |
| FIA | P3-only refinement | 相同 FIA 运算，并共享给局部专家 |
| B 的教师 | 后续 decoder 层分布的混合 | 图像局部专家的边界分布 |
| B 的推理作用 | 无，参数为零的训练损失 | 最终解码层后执行局部专家 |
| 特征入口 | P3/P4/P5 | P2/P3*/P4/P5 |

关键证据：

- `configs/rtdetr-l-fdr-bpdd-fia.yaml:39–53`：三尺度入口、preliminary box 和旧 BPDD 配方。
- `src/fdr_head.py:267–289`：实际使用 preliminary reference 和原始 distance2bbox。
- `src/fdr_loss.py:164–200`：原始 IoU 权重，无 LQS。
- `src/bpdd_loss.py:203–233`：未来层 softmin 混合教师。
- `src/rtdetr_fdr_bpdd.py:51`：明确说明 parameter-free BPDD。

当前对照配置为 `paper_material/evidence/visdrone_lrs_gfdr_capacity_v3_safe_joint_20260913/rtdetr-l-lrs-gfdr-capacity-v3-safe-bpdd-fia.yaml:37–64`；当前权威源码为 `paper_material/evidence/audit_remediation_20260915/source-a43056a/src/`。

上述证据直接判定的是归档源码身份。若打包时混用了旧代码与新结果，则实际模型仍可能不同，需用实际训练配置或 checkpoint 元数据确认。

## 5. 效率字段的使用

| 原始报告字段 | baseline | exp |
|---|---:|---:|
| 参数量 | 31,989,905 | 32,621,369 |
| GFLOPs | 103.4 | 107.1 |
| 验证器报告的推理摊销耗时（ms/图） | 4.824 | 5.463 |
| 推理速度（images/s） | 207.31 | 183.03 |
| 前处理＋推理＋后处理速度（images/s） | 195.10 | 172.48 |

参数增加 631,464（约 1.97%）。复杂度和速度仅作为本包报告原值保存：两份脚本均使用验证 batch=4，但缺少这次运行的硬件、精度、库版本和实际命令记录；GFLOPs 来自 model_info，未证明与论文当前专项计数的算子覆盖一致。

因此不能用这里的 183.03 images/s 替换现有论文 Full 的 batch=8、74.129 images/s，也不能把 5.463 ms 写成单张请求延迟。报告所谓“全程”仅是三个计时字段之和，不包含整个部署链路。

权重文件大小 63.2/193.4 MB 是保存容器大小；文件未随包提供，不能据此推断模型参数存储成本扩大三倍。

## 6. 对论文的处理

1. 保留本包两行总体指标和逐类指标，作为待确认版本的 UAVDT 对比材料。
2. 若确认实际使用包内代码，可准确命名为 FDR＋FIA＋跨层 BPDD 变体；这组数据不独立验证当前 GCDL 或局部专家。
3. 若确认结果来自新版，优先补实际运行的配置、日志或 checkpoint 结构信息，建立结果与模型的对应关系；此步骤本身不要求重训。
4. 保留现有 VisDrone 论文、模型图和速度表，避免将两个不同版本混入同一 Full 行。
5. 包内有真实预测蒙太奇，但主要为相邻夜间帧，文字重叠明显；可作核查素材。正式定性图还需明确对应模型、样本和统一展示阈值。
