A. Construction of ESCK
Cross-orientation suppression (COS) [1, 2] is a key neu-
ral modulation mechanism in the visual cortex. Its core
principle is as follows: when a neuron prefers a specific
orientation (such as vertical), if stimuli of other orienta-
tions (such as horizontal) appear in its receptive field, in-
hibitory interneurons reduce the firing rate of that neuron.
This enhances the response to the target orientation signal
while suppressing interference from non-preferred orienta-
tions. This mechanism has been extensively studied and
confirmed in the primary visual cortex (V1 area) and is one
of the fundamental bases for achieving orientation selectiv-
ity and information filtering in V1 neurons.
To simulate the COS mechanism, we designed eight ES-
CKs (Enhanced Selective Convolutional Kernels) in dif-
ferent directions. Inspired by the concept of pixel differ-
ence convolution [3], ESCK transforms the pixel differ-
ence in the output into a difference in convolutional kernel
weights. This enables the convolution operation to achieve a
response pattern that enhances same-orientation inputs and
suppresses cross-orientation inputs.

B. Experimental Support
Experimental Setup.The baseline model for small ob-
ject detection constructed in this study is based on the Ul-
tralytics framework (version 8.3.78), with the optimized
YOLO12 architecture as its core, as shown in Tab. A.
It is implemented in a PyTorch 2.7.1 environment. The
hardware configuration consists of a single NVIDIA RTX
3090Ti GPU with 24GB VRAM (CUDA 12.4 + cuDNN
9.5.1). For data augmentation, Mosaic augmentation, HSV
jitter (hsv h: 0.015; hsv s: 0.7; hsv v: 0.4), horizontal flip-
ping (p=0.5), and random erasing (p=0.4) were employed
to suppress overfitting.
Regarding training parameters, input images were uni-
formly resized to 640×640, with a batch size of 8. The op-
timizer used was SGD, with an initial learning rate of 0.01
and a warm-up phase lasting three epochs. After warm-up,
the learning rate was adjusted according to the scheduler,
decreasing by2×10 −5 per epoch. The total number of

Datasets.The VisDrone2019, NWPU VHR-10, and AI-
TODv2 datasets selected for this study exhibit significant
differences in terms of object size, background complexity,
and shooting perspective, enabling a comprehensive evalu-
ation of the model’s adaptability and robustness across var-
ious remote sensing scenarios.
The VisDrone2019 dataset originates from remote sens-
ing images captured from a drone perspective, simulating
real-world drone inspection scenarios. It is characterized by
typical small objects, dense distributions, and multiple oc-
clusions. Most object sizes are smaller than32×32pixels,
and they are noticeably affected by illumination variations
and perspective distortion. The dataset covers 10 object cat-
egories, including pedestrians and vehicles. According to
the official standard, it is divided into 6,471 training im-
ages, 548 validation images, and 1,610 test images, totaling
approximately 2.6 million annotated objects. The diversity
and complexity of this dataset make it an important bench-
mark for evaluating model performance in complex urban
scenarios [4].
The NWPU VHR-10 dataset consists of very high-
resolution (VHR) satellite imagery. Its main features are
the large contrast differences between objects and the back-
ground, as well as color or shape confusion in some cat-
egories (e.g., storage tanks, tennis courts), thereby testing
the model’s recognition capability under high-interference
backgrounds. This dataset contains 10 categories of artifi-
cial objects, such as airplanes and ships, with a total of 650
positive sample images containing object annotations and
150 negative sample images without targets. For the posi-
tive sample portion, the commonly used academic split ratio
of 8:1:1 was adopted, resulting in 520 training images, 65
validation images, and 65 test images [5].
The AI-TODv2 dataset focuses on aerial tiny object de-
tection. Its core characteristic is that the average object size
is only 12.8 pixels, significantly smaller than other remote
sensing datasets, and it contains a large number of sub-pixel
objects, making it highly challenging. This dataset covers
8 object categories, including airplanes and bridges, with a
uniform image resolution of800×800pixels. According

to the official split, the trainval set contains 11,214 train-
ing images and 2,804 validation images, while the test set
contains 14,018 test images, totaling 700,621 annotated in-
stances. This dataset provides an ideal testbed for evaluat-
ing model detection capability in very low-resolution and
extremely small object scenarios [6].
Evaluation Metrics.To comprehensively quantify
model performance, this study adopts general evaluation
metrics from the object detection field [7]. Following pre-
vious work, the NWPU VHR-10 dataset primarily uses
mAP50 (%) (mean Average Precision at an IoU threshold
of 0.5) as the core metric to highlight the model’s detection
accuracy for small objects and in high-resolution scenes.
For the VisDrone2019 dataset, based on mAP 50 (%), the
comprehensive metric mAP 50−95 (%) (mean Average Pre-
cision over IoU thresholds from 0.5 to 0.95) is further intro-
duced to more comprehensively evaluate the model’s detec-
tion performance in complex urban scenarios. Additionally,
the number of parameters (Params, M) and computational
complexity (GFLOPs) are reported to evaluate the model’s
inference efficiency and lightweight characteristics. The
evaluation for the AI-TODv2 dataset follows the COCO of-
ficial evaluation standard [8] to calculate AP (%) (overall
Average Precision), AP 50 (%) (AP at IoU=0.5), and AP 75
(%) (AP at IoU=0.75). Furthermore, to analyze the model’s
performance across different object scales, based on the
dataset’s scale division criteria, AP vt (%) (Average Preci-
sion for objects≤8 pixels), AP t (%) (8–16 pixels), AP s
(%) (16–32 pixels), and APm (%) (32–64 pixels) are further
calculated to comprehensively reveal the model’s detection
performance across tiny, very small, small, and medium-
sized objects.
C. Supplemental Analysis and Verification
This section provides visual analysis of feature maps related
to the core contributions of the main text. It also explores
the diversity of color spaces, validates the extension to de-
tection tasks, evaluates key component performance, and
assesses generalization capabilities and deployment value,
serving as a robust supplement to the experimental analysis
in the main text.
Visual Analysis of Feature Maps.To clearly demon-
strate the model’s enhancement of key target features, we
extracted and visualized feature maps before and after pro-
cessing by CAM, VCHM, OrSM, and FFM, as shown in
Fig. A. CAM and VCHM significantly improve color con-
trast, which manifests as strong activations in high-contrast
regions on the feature maps, while values in low-contrast
regions change smoothly, exhibiting consistent responses
across the area. Furthermore, to demonstrate that OrSM
possesses stronger orientation selectivity, we conducted a
frequency domain analysis. As shown in Fig. B, in the
frequency domain, line brightness reflects response inten-
sity for specific orientations, confirming that OrSM exhibits
powerful orientation selectivity.
