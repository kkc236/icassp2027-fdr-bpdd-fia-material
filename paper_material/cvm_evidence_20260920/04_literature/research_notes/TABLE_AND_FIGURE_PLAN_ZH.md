## 3. 表格方案：每张表回答一个问题

### Table 1：完整模型 test 表现——两个独立面板

放在 4.2 开头，一张双栏宽表，两个面板使用独立标题和独立数值列。可左右并排，若字号不足则上下排，不强行造一个共用排序。

**面板 A：Native evaluation / validation-selected checkpoints。** 两行：RT-DETR-L、Full。列：Model、AP、AP50、AP75。对应现有 17.743→23.604 的完整系统比较。

**面板 B：Common evaluation / final checkpoints。** 两行：D-FINE-L reproduction、Full。列：Model、AP、AP50、AP75、APs。对应现有 22.554→24.133 的 primary comparison。

必要要求：

- 面板名称应在视觉上比协议脚注更明显，Full 在两个面板各出现一次，不能把其 23.604 与 24.133 当成可互换的模型分数。
- 只在各面板内部加粗最高值；不画跨组总排名，不按混合 AP 排序，不计算 native 与 common 之间的差值。
- native 的 APs 若没有现成受审核结果，直接不设此列，不补数、不制造一列横线。
- common best 端点移至现有附录敏感性表和短文本，主表不再为 secondary endpoint 复制两行完整指标。
- 转换标签、common reproduction、不同训练配方、final 主端点在图注/设置中各有明确位置；无须每行反复写解释。
- 此表不放异来源 Params、GFLOPs 或 FPS；完整系统比较与运行成本各有独立证据来源。

## 4. 气泡图：准备两个合法版本

### A. 外部 context 版：推荐作为文献定位图的候选首图

横轴 Params (M)，纵轴 AP (0.50:0.95)，圆面积与 GFLOPs 成正比。所有点须具备同一行/同一配置的三项来源值和输入尺寸；标签给模型名、来源引用或来源编号。对本稿点另标 `our converted-label evaluation`，对外部点标 `reported`，不能统一写成 `re-evaluated`。

本次实际主表可核实的例子：LME-DETR 为 14M、46G、31.8 AP；SD-Net-s 为 14.2M、61.2G、29.3 AP；FGHDet 在 640 输入下为 43.90M、32.10 AP，但其这张主表没有 GFLOPs，因此不能只凭该表造一个带面积含义的气泡。其他候选由来源审核补足。

该图若取代原文献背景表，可减少重复展示同一组数字；不应把 7 张表再配一张含同样数字的装饰图。

## 6. 新总图的具体画法

借鉴的是参考论文的层级，不是其装饰或全部模块数量：

1. 顶部一条明确的预测数据流。用分辨率不同的特征平面、边分布小直方图、框与采样区域表达实际对象，减少纯文字矩形。
2. 继承部分用低饱和灰色，GCDL 核心用一种主色，局部扩展用辅助色；训练路径统一虚线。核心面积和对比度不应低于专家扩展。
3. 固定分布参考系、incoming reference、geometry 和 LQS 的关系用就近的细节框交代，归属写在短标签/图注和正文。删除机制表后，这些信息仍需存在，但无需再画成一张文字表。
4. shared P3 要画出分叉，P4 保持原始 P3 构造的事实不能在视觉上改成 refinement 继续向所有尺度传播。
5. 专家位于实线预测路径内；只有选择性传递是训练虚线。不能通过图把专家误画成训练后可丢弃的教师。
6. 不使用未经推理得到的图片检测框冒充本稿输出。若有真实输入图可合法复用，只作输入；输出用明确的机制示意，当前版不加入逐图预测案例。
